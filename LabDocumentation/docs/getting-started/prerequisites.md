# Prerequisites

Before setting up the Healthcare Database Security Testing Lab, ensure you have the following requirements in place.

## Hardware Requirements

### Frontend/Backend Host
- **RAM:** 12GB minimum
- **CPU:** 2 vCPUs minimum
- **Storage:** 100GB minimum
- **Network:** 1 Gbps network interface

### Database Host
- **RAM:** 16GB minimum
- **CPU:** 2 vCPUs minimum
- **Storage:** 100GB minimum
- **Network:** 1 Gbps network interface

### LLM Host
- **RAM:** 32GB minimum (physical machine recommended)
- **CPU:** Intel Core Ultra 5 or equivalent
- **Storage:** 1TB minimum (for model storage)
- **Network:** 1 Gbps network interface

## Software Requirements

### Hypervisor
- **VMware Workstation:** 17.6.2 or later
- **Alternative:** VirtualBox, Proxmox, KVM, or any hypervisor supporting Ubuntu

### Operating Systems
- **Ubuntu 24.04 LTS** - For Frontend/Backend and LLM hosts
- **Ubuntu 25.04** - For Database host
